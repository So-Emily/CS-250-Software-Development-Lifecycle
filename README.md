# CS 250 SNHU Travel Project
## Wellness Travel Slideshow 🧘‍♀️

This is a small Java project I built for a class assignment while learning Agile development.

The goal was to take an existing slideshow app and update it based on new requirements from a "Product Owner." Instead of general travel destinations, the focus shifted to wellness and detox travel.

## What it does

- Displays a slideshow of 5 wellness destinations  
- Each slide includes an image and short description  
- Users can click Next and Previous to navigate  

## Destinations included

- Tulum, Mexico  
- Greek Islands  
- Ubud, Bali  
- Aspen, Colorado  
- New York City  

## Tech

- Java  
- Swing (GUI)

## What I practiced

This project was more about adapting code than building from scratch.

- Updating existing code to match new requirements  
- Fixing layout/UI issues  
- Working in an Agile mindset where priorities can change  

## Favorite part

The wellness theme was my favorite update — it made the slideshow feel more intentional instead of random locations. Also kind of funny that everything turned into yoga.
